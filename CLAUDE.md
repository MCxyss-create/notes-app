# Мысли — личное iOS-приложение: заметки, идеи, напоминания

Владелец пишет по-русски, Swift не знает. Полный план с объяснениями:
https://claude.ai/code/artifact/42ecb5d0-3680-4a14-96ec-ebeb89d9fcc7

## Суть

Открыл приложение → сразу поле ввода → написал или надиктовал фразу → DeepSeek
раскладывает её на записи (заметка / идея / напоминание с датой) → карточка
«вот что я понял» → сохранить. Напоминания приходят локальными уведомлениями,
даже если приложение закрыто и нет интернета.

## Жёсткие условия

- У владельца только Windows 10, Mac нет. Телефон на iOS 26.
- Собирать можно ТОЛЬКО в GitHub Actions (`.github/workflows/build.yml`, `macos-latest`).
- Платного Apple Developer нет. Сборка без подписи (`CODE_SIGNING_ALLOWED=NO`),
  подписывает Sideloadly бесплатным Apple ID. Подпись живёт 7 дней.
- Значит НЕЛЬЗЯ: пуш-уведомления (APNs), iCloud / CloudKit, Sign in with Apple,
  платные entitlements. Всё должно работать без сервера.
- `.xcodeproj` в репозитории нет и руками не правится. Проект описан в `project.yml`
  (XcodeGen). Новый файл `.swift` в папке `NotesApp/` подхватывается сам.
- Никаких ключей и секретов в репозитории. Ключ DeepSeek вводится в настройках
  приложения и хранится в Keychain.

## Правила работы

1. Чинить только место поломки. Рабочий код заодно не переписывать.
2. Не нашёл место для правки — остановиться и показать, что искал, а не править наугад.
3. После каждого изменения — пуш в `main` и зелёная сборка:
   `gh run watch` → при ошибке смотреть логи → исправить → повторить.
   Логи, ошибки (`errors.txt`), результаты тестов и снимки экранов последнего запуска
   лежат в ветке `ci-results`: `git fetch origin ci-results && git show origin/ci-results:errors.txt`.
   Если `gh run view --log` недоступен из-за сети — читать только эту ветку.
4. Объяснения владельцу — коротко, по-русски, без теории. При ошибке — прямо и с числами.
5. В конце каждой задачи: что сделано, номер сборки, ссылка на артефакт,
   что проверить на телефоне.

## Стек

- SwiftUI, iOS 17.0+, Swift 5 language mode.
- SwiftData — хранилище записей (только на телефоне).
- UserNotifications — локальные уведомления.
- DeepSeek API, формат OpenAI: `POST https://api.deepseek.com/chat/completions`,
  модель `deepseek-flash`, `"thinking": {"type": "disabled"}`,
  `"response_format": {"type": "json_object"}`. Адрес и модель — в настройках.
- Резервная копия — экспорт/импорт JSON через «Файлы».

## Уведомления

- Точное — в `dueAt`; заранее — за `remindBeforeMin` (по умолчанию 15).
- Утренняя сводка 08:00, если на сегодня есть дела. План на завтра 21:00 (выключаемый).
- Кнопки в уведомлении: «Готово», «Через час», «Завтра».
- Лимит iOS — 64 запланированных уведомления: ставить ближайшие 60 (4 места —
  под проверочное и сводки), пересчитывать при открытии приложения и при любом
  изменении записей (`RootView.signature` → `NotificationPlanner` → `NotificationService`).
- Напоминание о переподписи за сутки до конца срока: дату читать из
  `embedded.mobileprovision` внутри приложения.

## DeepSeek: ответ, который ждёт приложение

```json
{"items":[{"kind":"reminder","title":"Подойти к учителю","body":null,
  "due":"2026-10-17T09:00:00+03:00","time_given":false,
  "remind_before_min":15,"repeat":null,"tags":["школа"]}],
 "reply":"Напоминание на завтра 09:00."}
```

В системный промт подставлять: текущие дату и время, день недели, часовой пояс
(Europe/Moscow), время по умолчанию для дня без часа (09:00), напоминание заранее
по умолчанию (15). Черновик промта и 8 контрольных фраз — в плане по ссылке выше.
Ответ модели не принимать на веру: проверять JSON, пустой заголовок, дату в прошлом.

Где что лежит: промт — `Logic/AIPrompt.swift`, проверка ответа — `Logic/AIParser.swift`,
8 контрольных фраз — `Logic/AIControlCheck.swift`, запрос — `Services/DeepSeekClient.swift`,
«Входящие» (фраза не разобралась: нет сети, ключа, ошибка) — `InboxEntry` + `InboxProcessor`.
Фраза из «Входящих» разбирается от момента, когда сказана (`createdAt`), а не от «сейчас».
Имя модели: `deepseek-flash` — V4.1 Flash с 10.09.2026; если DeepSeek ответит «Model Not Exist»,
поменять модель в настройках приложения (например, `deepseek-v4-flash`), пересборка не нужна.

## Этапы

- [ ] **0. Сборка и установка** — пустое приложение открывается на iPhone.
      Сборка зелёная (№1). Установка отложена: Sideloadly получил HTTP 503 от
      gsa.apple.com (вход Apple ID) — пробовать без VPN.
- [ ] **1. Записи и уведомления без ИИ** — лента «Просрочено / Сегодня / Завтра / Позже»,
      поле ввода внизу, три вида записей, дата и время, SwiftData, локальные уведомления,
      свайп вправо — выполнено, влево — отложить.
      Проверка: напоминание на +2 минуты приходит при закрытом приложении.
      Код готов (сборка 3, 16 тестов зелёные, снимки ок). Разделы переключаются вкладками
      сверху, а не свайпом: горизонтальный свайп по строке занят. Ждёт проверки на телефоне.
- [ ] **2. DeepSeek** — настройки (ключ, адрес, модель), запрос, карточки подтверждения,
      без сети — во «Входящие». Проверка: 8 контрольных фраз разобраны верно.
      Код готов: кнопка ✨ у поля ввода (по умолчанию включена), карточки «Вот что я понял»,
      «Входящие» над лентой. Проверка на телефоне — Настройки → «Проверить разбор: 8 фраз».
      Ждёт ключа и проверки на телефоне.
- [ ] **3. Удобство** — кнопки в уведомлениях, сводки, повторы, поиск, теги,
      экспорт/импорт, напоминание о переподписи, своя кнопка микрофона.
- [ ] **4. Запись без открытия** — Кнопка действия (App Intent), Siri, виджет,
      «Поделиться». Проверить на бесплатном Apple ID.

Этапы 0–3 — до 5 ноября 2026.

## Как проверять без телефона

- Автотесты логики — папка `NotesAppTests` (даты, блоки ленты, план уведомлений).
- Снимки экранов: сборка запускает приложение на виртуальном iPhone с `-demo <экран>`
  (`feed`, `due`, `edit`, `ideas`, `notes`, `settings`, `empty`, `review`, `inbox`) — база в памяти с примерами
  из `DemoData`. Снимки — в ветке `ci-results/screens` и на странице запуска.
- Новый экран → добавить вариант в `DemoConfig.Screen` и строку `shot` в `build.yml`.
- Живая проверка 8 фраз на DeepSeek в сборке — только если в GitHub есть секрет
  `DEEPSEEK_API_KEY` (Settings → Secrets and variables → Actions). Итог — на странице запуска
  и в `ci-results:ai-check.txt`. Без секрета тест пропускается, сборку не роняет.

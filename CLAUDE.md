# Мысли — личное iOS-приложение: заметки, идеи, напоминания

Владелец пишет по-русски, Swift не знает. Полный план с объяснениями:
https://claude.ai/code/artifact/42ecb5d0-3680-4a14-96ec-ebeb89d9fcc7

## Суть

Открыл приложение → сразу поле ввода → написал или надиктовал фразу → DeepSeek
раскладывает её на записи (заметка / идея / напоминание с датой) → карточка
«вот что я понял» → сохранить. Напоминания приходят локальными уведомлениями,
даже если приложение закрыто и нет интернета.

## Жёсткие условия

- У владельца только Windows 10, Mac нет. Телефон на iOS 26.
- Собирать можно ТОЛЬКО в GitHub Actions (`.github/workflows/build.yml`, `macos-latest`).
- Платного Apple Developer нет. Сборка без подписи (`CODE_SIGNING_ALLOWED=NO`),
  подписывает iloader (Windows, «Import IPA») бесплатным Apple ID. Подпись живёт 7 дней.
  Sideloadly с 12–13.10.2026 не входит в Apple ID (HTTP 503 от gsa.apple.com) — не советовать.
- Значит НЕЛЬЗЯ: пуш-уведомления (APNs), iCloud / CloudKit, Sign in with Apple,
  платные entitlements. Всё должно работать без сервера.
- `.xcodeproj` в репозитории нет и руками не правится. Проект описан в `project.yml`
  (XcodeGen). Новый файл `.swift` в папке `NotesApp/` подхватывается сам.
- Никаких ключей и секретов в репозитории. Ключ DeepSeek вводится в настройках
  приложения и хранится в Keychain.

## Правила работы

1. Чинить только место поломки. Рабочий код заодно не переписывать.
2. Не нашёл место для правки — остановиться и показать, что искал, а не править наугад.
3. После каждого изменения — пуш в `main` и зелёная сборка:
   `gh run watch` → при ошибке смотреть логи → исправить → повторить.
   Логи, ошибки (`errors.txt`), результаты тестов и снимки экранов последнего запуска
   лежат в ветке `ci-results`: `git fetch origin ci-results && git show origin/ci-results:errors.txt`.
   Если `gh run view --log` недоступен из-за сети — читать только эту ветку.
4. Объяснения владельцу — коротко, по-русски, без теории. При ошибке — прямо и с числами.
5. В конце каждой задачи: что сделано, номер сборки, ссылка на артефакт,
   что проверить на телефоне.

## Стек

- SwiftUI, iOS 17.0+, Swift 5 language mode.
- SwiftData — хранилище записей (только на телефоне).
- UserNotifications — локальные уведомления.
- DeepSeek API, формат OpenAI: `POST https://api.deepseek.com/chat/completions`,
  модель `deepseek-flash`, `"thinking": {"type": "disabled"}`,
  `"response_format": {"type": "json_object"}`. Адрес и модель — в настройках.
- Резервная копия — экспорт/импорт JSON через «Файлы».

## Папки

- `@Model Folder` (`Model/Folder.swift`): uid, name, colorRaw (8 цветов), symbol (8 значков), parentID
  (nil — верхний уровень, связь без `@Relationship`), sortIndex, createdAt. В `ModelContainer` —
  в `MysliApp.swift` и `AppModel.sharedContainer`.
- Правила — `Logic/FolderTree.swift` (тесты `FolderTreeTests`): до 3 уровней, имя уникально среди
  соседей («ё» = «е», без регистра), нельзя в себя и в подпапку, путь «Проекты / VPN / Реклама».
  Удаление (`FolderStore.delete`) не теряет записи: записи и подпапки — к родителю (наверху —
  «Без папки»), совпавшее имя подпапки → «Реклама 2».
- Экраны: «Идеи»/«Заметки» (`ItemListView`) — раздел «Папки» сверху, ниже записи без папки;
  папка (`FolderView`) — вложенные папки и её записи. Меню папки (долгое нажатие) и листы —
  `FolderSection` + `.folderSheets` в `FolderView.swift`; форма и выбор деревом — `FolderEditView.swift`.
  Папка записи — в карточке записи, «В папку…» в меню строки, в правке карточки ИИ.
- Поле ввода одно на весь стек (`safeAreaInset` у `NavigationStack` в `RootView`): в открытой
  папке новые записи ложатся в неё (`ComposerBar.folderID`), с ✨ — если ИИ не выбрал другую.
  Экраны внутри стека этот отступ не видят — им место под полем даёт `composerSpace(высота поля)`.
- Поиск находит и по имени папки, путь — серым под результатом.
- Резервная копия версии 2: `BackupItem.folderID`, `BackupFile.folders`; версия 1 читается как раньше.

## Фото

- `@Model PhotoAttachment` (`Model/PhotoAttachment.swift`): uid, itemID (связь без `@Relationship`),
  createdAt, sortIndex, `imageData` (JPEG, `.externalStorage`), thumbData (миниатюра), byteCount.
  К любой записи, до 10 штук (`PhotoMath.limit`). Только на телефоне и в копии, в DeepSeek не уходят.
- Подготовка (`Services/PhotoStore.swift`): длинная сторона до 2048 px, JPEG 0.8, миниатюра 300 px;
  ориентация учтена (ImageIO с поворотом по EXIF, камера — перерисовка). Размеры — `Logic/PhotoMath.swift`.
- Удаление записи — `PhotoStore.deleteItem` (лента, списки, карточка, ИИ-команда «удали»);
  при запуске `PhotoStore.removeOrphans` убирает фото без записи.
- Экраны: карточка записи — раздел «Фото» (сетка, «Добавить фото» → галерея `PhotosPicker` / камера
  `CameraPicker`, «3 из 10»); просмотр — `Views/PhotoViewer.swift` (листать, щипок и двойной тап,
  «Поделиться», «Удалить», свайп вниз); строка — миниатюра справа и 📷 с числом (`ItemRow`);
  поле ввода — 📷 рядом с ✨, полоска миниатюр над полем. С ✨ фото идут к первой карточке ИИ,
  в правке карточки — «Перенести фото сюда» (`AIReview.photoDraft`). Общие пикеры — `Views/PhotoPickers.swift`.
- Info.plist: `NSCameraUsageDescription`, `NSPhotoLibraryAddUsageDescription` (без неё «Сохранить
  изображение» из «Поделиться» уронит приложение).
- Резервная копия версии 3: `BackupFile.photos` (base64), переключатель «С фото» и строка
  «Фото: N шт., X МБ» в Настройках; миниатюры при восстановлении делаются заново.

## Уведомления

- Точное — в `dueAt`; заранее — за `remindBeforeMin` (по умолчанию 15).
- Повторы (`RepeatMath`): уведомления на каждый повтор, не дальше 35 дней и не больше 8 раз.
  «Готово» у повторяющегося дела переносит `dueAt` на следующий раз (`ItemActions.complete`).
  Повторяющееся дело не откладывается (сдвинулся бы весь повтор) — у него только «Готово».
- Сводки (`SummaryPlanner`): утро 08:00 — дела дня + сколько просрочено; вечер 21:00 — дела
  завтра. На 3 дня вперёд, только если есть дела. Время и вкл/выкл — в настройках.
- Кнопки в уведомлении: «Готово», «Через час», «Завтра» (категории — `NotificationActionID`).
  Работают без открытия приложения: iOS будит его в фоне → `NotificationActions.handle`
  берёт базу из `AppModel.container`, меняет запись и пересчитывает уведомления.
- Лимит iOS — 64: дела 56 ближайших, сводки до 6, переподпись 1, проверочное 1.
  Всё пересчитывает `NotificationScheduler.rescheduleAll` — при открытии приложения,
  закрытии настроек и любом изменении записей (`RootView.signature`).
- Переподпись (`ResignPlanner`, `ProvisionInfo`): дата из `embedded.mobileprovision`,
  уведомление за сутки (поздно — за 2 часа), плашка в ленте за 2 дня. В сборке GitHub
  профиля нет — «нет данных», это нормально.
- «Срочные» (Time Sensitive, `NotificationLevel.for(id:)`): дела (`item-…`), переподпись и
  проверочное (`test-…`) — `.timeSensitive`; сводки — `.active`. Ограничение iOS: уведомления
  идут по времени, закрепить свои над чужими нельзя; срочные только пробивают Фокус и «Не
  беспокоить» и дольше висят на экране блокировки. Разрешение — `NotesApp/NotesApp.entitlements`
  (`CODE_SIGN_ENTITLEMENTS`); сборка без подписи, поэтому `build.yml` подписывает `.app` ad-hoc
  с ним перед упаковкой, проверка — `ci-results:entitlements.txt`. iloader (isideload) ставит
  разрешения «по минимуму» — если срочные не дошли, iOS покажет их как обычные, не падает.
  Состояние и подсказка — Настройки → «Чтобы «Мысли» были сверху».

## DeepSeek: ответ, который ждёт приложение

```json
{"items":[{"kind":"reminder","title":"Подойти к учителю","body":null,
  "due":"2026-10-17T09:00:00+03:00","time_given":false,
  "remind_before_min":15,"repeat":null,"tags":["школа"]}],
 "reply":"Напоминание на завтра 09:00."}
```

В системный промт подставлять: текущие дату и время, день недели, часовой пояс
(Europe/Moscow), время по умолчанию для дня без часа (09:00), напоминание заранее
по умолчанию (15). Черновик промта и 8 контрольных фраз — в плане по ссылке выше.
Ответ модели не принимать на веру: проверять JSON, пустой заголовок, дату в прошлом.

Где что лежит: промт — `Logic/AIPrompt.swift`, проверка ответа — `Logic/AIParser.swift`,
8 контрольных фраз — `Logic/AIControlCheck.swift`, запрос — `Services/DeepSeekClient.swift`,
«Входящие» (фраза не разобралась: нет сети, ключа, ошибка) — `InboxEntry` + `InboxProcessor`.
Фраза из «Входящих» разбирается от момента, когда сказана (`createdAt`), а не от «сейчас».
Команды (`Logic/AICommands.swift`): вместе с фразой уходит список несделанных записей
(`AIContext.forPrompt`: 40 ближайших дел + 20 свежих идей/заметок, id — первые 6 знаков uid).
В ответе кроме `items` — `"changes":[{"op":"done|move|delete|edit","id":…}]` и для вопросов
`"found":[id…]`. Изменения показываются карточками и применяются только по кнопке
(`AIService.apply`); через Siri удалять нельзя. Промт также чистит надиктованное от слов-паразитов.
Проверка на телефоне — 8 фраз + 4 команды (`AIControlCheck.commandCases`) + 2 про папки (`folderCases`).
Папки: в промт уходит список `- f1a2b3 | Проекты / VPN` (`AIKnownFolder`, `AIPrompt.folderRules`).
У идеи/заметки в ответе `"folder":"<id>"` или `null`; «создай папку X» — `"folder_new":"X"` (папку
создаёт `AIService.save`, такая уже есть — кладёт в неё). Команда «перенеси … в папку X» —
`{"op":"folder","id":…,"folder":…}`. Незнакомая папка — без папки, дела в папки не кладутся.
Имя модели: `deepseek-flash` — подтверждено официальной страницей цен DeepSeek
(api-docs.deepseek.com/quick_start/pricing, проверено 16.10.2026): «Use `deepseek-flash` as the model
name»; старое `deepseek-v4-flash` тоже принимается и уходит на ту же V4.1 Flash. Модель меняется
в настройках приложения, пересборка не нужна.

## Как проверять без телефона

- Автотесты логики — папка `NotesAppTests` (даты, блоки ленты, план уведомлений).
- Снимки экранов: сборка запускает приложение на виртуальном iPhone с `-demo <экран>`
  (`feed`, `due`, `edit`, `ideas`, `notes`, `settings`, `empty`, `review`, `inbox`, `search`, `listen`, `command`,
  `keyboard`, `editKeyboard`, `searchKeyboard` — с открытой клавиатурой, `urgent` — блок срочных
  уведомлений в настройках, `folders` — «Идеи» с папками, `folder` — внутри «Проекты / VPN»,
  `photos` — карточка идеи с 3 фото (рисуются в коде), `viewer` — фото на весь экран) —
  база в памяти с примерами
  из `DemoData`. Снимки — в ветке `ci-results/screens` и на странице запуска.
- Новый экран → добавить вариант в `DemoConfig.Screen` и строку `shot` в `build.yml`.
- Живая проверка 8 фраз на DeepSeek в сборке — только если в GitHub есть секрет
  `DEEPSEEK_API_KEY` (Settings → Secrets and variables → Actions). Итог — на странице запуска
  и в `ci-results:ai-check.txt`. Без секрета тест пропускается, сборку не роняет.

# Мысли

Личное iPhone-приложение: заметки, идеи и напоминания с разбором фраз через DeepSeek.
Собирается в GitHub Actions без Mac, ставится через Sideloadly.

## Как поставить на iPhone

1. Вкладка **Actions** → последний зелёный запуск **Build IPA** → блок **Artifacts** →
   скачать `NotesApp-build-N`. Это zip, внутри `NotesApp.ipa`.
2. Подключить iPhone к ПК кабелем, разблокировать, нажать «Доверять».
3. Открыть Sideloadly → перетащить `NotesApp.ipa` → ввести Apple ID → **Start**.
4. Первый раз на iPhone:
   - Настройки → Конфиденциальность и безопасность → **Режим разработчика** → включить,
     телефон перезагрузится.
   - Настройки → Основные → VPN и управление устройством → свой Apple ID → **Доверять**.
5. Раз в 7 дней повторить шаг 3 — записи сохраняются.

## Устройство

- `project.yml` — описание проекта для XcodeGen (`.xcodeproj` генерируется в облаке).
- `NotesApp/` — код приложения на SwiftUI.
- `.github/workflows/build.yml` — сборка неподписанного `.ipa`.
- `CLAUDE.md` — правила и план для Claude Code.
